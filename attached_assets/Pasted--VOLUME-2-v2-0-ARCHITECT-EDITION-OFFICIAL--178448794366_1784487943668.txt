==========================================================
SERVER AUTHORITY
==========================================================

The server is always authoritative.

Clients display information only.

Clients never decide gameplay.

Clients never calculate official results.

Clients never modify match state.

Clients never generate official outcomes.

Every gameplay decision must originate from the server.

==========================================================
CLIENT RESPONSIBILITIES
==========================================================

The client may only

Display cards

Display timers

Display animations

Display scores

Send player actions

Receive server updates

Render game state

The client must never determine

Winner

Score

Turn validity

Trump validity

Match completion

Penalty
